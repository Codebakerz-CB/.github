# CodeBakerz

**Baking Your Code To Give You A Pie**

Live, small-batch coding mentorship in Hinglish for school students, college students and job seekers. An initiative by [Aryavrut](https://aryavrut.com).

## Programmes

| Track | Who it is for |
|---|---|
| Starter | Class 6 to 10, complete beginners |
| Builder | Class 11 to 12, college students and adult beginners |
| Career | Final-year students, graduates and job seekers |

## How it works

- Two live 90-minute classes a week, plus a weekly doubt-solving lab
- One project a month, reviewed by a mentor with written feedback
- Courses across Python, web development, AI/ML, cybersecurity, cloud/DevOps and mobile apps

## Code for Good

Our Code for Good mentorship sessions are recorded and published on [YouTube](https://youtube.com/@codebakerz).
